# Sub-project 9A: Web UI/UX Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the entire GateKeep web app into the owner-approved "Ember, Deeper Night"
design language, with dark and light themes, while leaving every behavior byte-identical.

**Architecture:** Tailwind v4 + copied shadcn/ui components themed by a CSS-variable token set;
one shell; signature components (gig card, date-block row, hero carousel) reused everywhere;
pages restyled group by group.

**Tech Stack:** Tailwind CSS v4, shadcn/ui (copied), next/font (Syne + Sora),
@phosphor-icons/react (one weight), motion, existing Next.js 16 app.

**Spec:** `docs/superpowers/specs/2026-08-28-web-uiux-design.md` (binding; referenced by
section below as "spec §N")
**Visual references (owner-approved mocks):** `docs/superpowers/mocks/sp9a/*.html` (open in a
browser; these carry the exact approved layouts and hex values)

## Global Constraints

- **UI ONLY.** No change to callables, queries, data shapes, firestore rules, or functions/.
  The two sanctioned additions: the past-shows page (Task 9) and legal pages (Task 4), both
  UI over existing readable data.
- **The antislop skills are BINDING.** Every implementer reads
  `~/.claude/skills/antislop/SKILL.md` + `~/.claude/skills/antislop-ui/SKILL.md` before coding
  (plus `antislop-copywriting/SKILL.md` when writing copy). Reviewers run the antislop UI
  checklist. The owner's blocklist highlights: NO em dashes anywhere (copy, comments, code
  strings), no lucide, no Inter/Geist/Space Grotesk, glass capped at exactly two uses (landing
  nav, mini-player), no bento grids, no three-feature-card rows, no invented numbers, no
  sparkle icons, no decorative arrows, no hover-everything.
- **Tokens only**: no raw hex in components; every color reads a CSS variable from Task 1.
  Both themes must pass WCAG AA; check contrast when deriving any new tint.
- **Radius tiers** (spec §2): pills only for primary CTAs and chips; 10px cards/inputs; 6px
  small controls. Shadows only on overlays.
- **Accent dosage**: ember on the primary action, price, brand, active nav, and status tints.
  Never on borders, body links, and icons at the same time.
- House verification per task: `pnpm --filter @gatekeep/web lint` and
  `pnpm --filter @gatekeep/web build` green (run `pnpm --filter @gatekeep/web exec next typegen`
  first if PageProps errors appear). Behavior gates (`pnpm typecheck`, emu suites) only in the
  final task since no logic changes.
- Visual review: the CONTROLLER captures screenshots (dark + light, 360/768/1280 widths) after
  each task's report and attaches paths to the review dispatch. Implementers do not need a
  browser.
- Commit prefix `feat(sp9a):` / `docs(sp9a):`.

- [ ] **Step 2:** Rewrite `globals.css` starting with `@import "tailwindcss";` then the token
  block, verbatim values from spec §2:

```css
:root, [data-theme="dark"] {
  --gk-bg-0: #0E0B13; --gk-bg-1: #150F20; --gk-bg-2: #1D1229;
  --gk-surface: #1A1424; --gk-border: #2C2438;
  --gk-text: #F5F1F8; --gk-muted: rgba(245,241,248,.62);
  --gk-accent: #FF6B4A; --gk-on-accent: #2A0F0A;
  --gk-success: #7BC48A; --gk-warning: #E8B15C; --gk-destructive: #E5484D;
  --gk-scrim: linear-gradient(to top, var(--gk-bg-0) 4%, rgba(14,11,19,.35) 55%, transparent);
  --gk-page: linear-gradient(165deg, var(--gk-bg-0) 0%, var(--gk-bg-1) 55%, var(--gk-bg-2) 100%);
}
[data-theme="light"] {
  --gk-bg-0: #FAF7F2; --gk-bg-1: #FAF7F2; --gk-bg-2: #FAF7F2;
  --gk-surface: #FFFFFF; --gk-border: #E4DDD2;
  --gk-text: #1C1524; --gk-muted: rgba(28,21,36,.62);
  --gk-accent: #FF6B4A; --gk-on-accent: #2A0F0A;
  --gk-success: #2E7D43; --gk-warning: #9A6A1B; --gk-destructive: #C62A30;
  --gk-page: #FAF7F2;
}
```
  plus an `@theme inline` block mapping these to Tailwind color names (`gk-surface`, etc.),
  body defaults (`background: var(--gk-page); color: var(--gk-text); font-family: var(--font-sora)`),
  and system-preference handling: with no `data-theme` attribute, a
  `@media (prefers-color-scheme: light)` block applies the light set.
- [ ] **Step 3:** `layout.tsx`: `next/font/google` Syne (600,700,800; variable `--font-syne`) and

- [ ] **Step 4:** `ThemeToggle.tsx`: three-state cycle button (System / Light / Dark) writing

- [ ] **Step 5:** Write repo-root `DESIGN.md`: the full token table, font roles, radius tiers,
